## Text or Trap? - SMS Phishing Detection in Filipino SMS Messages using Naive Bayes and Ensemble-based Random Forest Classifiers.
A partial fullfilment for the final requirement for the elective subject COMP 034 - Introduction to Data Science

## Proponets
- Callanga, Aaron Dave D.
- Domaoal, Lei Andrei E.
- Monton, Sean Paul M.

## Overview
This project aims to detect and determine a phishing sms message from a legitimate message using a PH-based SMS dataset, and to create a classifier model using Multinomial Naive Bayes acting as a baseline model, and an ensemble-based Random Forest Classifier to act as a more complex model. The workflow for this project follows the industry-standard CRISP-DM Framework.
